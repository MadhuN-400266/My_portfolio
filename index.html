Learn HTML the Simple Way

A clean, beginner-friendly starting point for anyone learning how to build websites with plain HTML5. No frameworks, no distractions — just the fundamentals.

About

This website is a beginner web development learning project built to practice writing clean, semantic HTML5 from scratch. It focuses purely on structure and markup, without relying on CSS frameworks or JavaScript.

The goal is to understand how elements like <header>, <nav>, <main>, <section>, and <footer> work together to create an organized and accessible page layout.

Whether you are following along or exploring the code yourself, this project is meant to serve as a simple, readable example of good HTML habits for anyone just getting started.
