# Day 6 - Media Queries & Responsive Design

## Overview

Today I learned how to make a website adapt to different screen sizes using **CSS Media Queries**. Instead of creating separate websites for different devices, I learned how one website can provide a great experience on mobile phones, tablets, and desktops by applying different CSS rules based on screen size.

## What I Learned

- Understanding the purpose of Media Queries.
- Creating responsive layouts for different devices.
- Optimizing navigation for smaller screens.
- Adjusting typography for better readability.
- Making images responsive.
- Improving spacing and layout on mobile devices.
- Testing responsiveness using Chrome Developer Tools.

## Challenges Faced

While testing my portfolio on mobile devices, I noticed that the navigation header remained expanded and covered the page content.

After debugging, I learned that:

- A `position: sticky` header behaves differently on smaller screens.
- Media Queries can be used to change layout behavior for mobile devices.
- Responsive design involves more than resizing elements—it also requires adapting layouts for usability.

## Code Improvements

- Added Media Queries for mobile, tablet, and desktop.
- Improved navigation layout on smaller screens.
- Optimized the hero section for mobile devices.
- Adjusted font sizes for better readability.
- Made images scale correctly across devices.
- Removed unnecessary CSS and identified duplicate styles for future refactoring.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git & GitHub

## Key Takeaway

Responsive web design is not just about making a website fit different screens. It's about creating a consistent and enjoyable user experience regardless of the device someone uses.

Every improvement made today brought my portfolio one step closer to professional web development standards.
