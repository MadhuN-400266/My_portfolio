# Day 12

## Task

Deploy the portfolio using GitHub Pages and make it accessible online.

## What I Completed

- Published my portfolio using GitHub Pages.
- Configured the repository settings for deployment.
- Learned the difference between working locally and hosting a live website.
- Verified that my portfolio was accessible through a public URL.
- Tested the live website to ensure navigation and links were working correctly.
- Updated my GitHub repository with the latest portfolio changes.

## What I Learned

Before today, I had heard of GitHub Pages but never understood why developers used it.

Today I learned that GitHub Pages is much more than a place to store code—it can also host a static website directly from a GitHub repository. This helped me understand the complete workflow of building a project locally, pushing it to GitHub, and making it available for anyone to visit through a live link.

I also learned the difference between developing a website on my computer and deploying it so others can access it online. Seeing my own portfolio live on the internet made the project feel more real and gave me a better understanding of how websites are shared with the world.

## Skills Gained

- GitHub Pages Deployment
- Git & GitHub Workflow
- Static Website Hosting
- Repository Configuration
- Website Testing
- Deployment Verification

## Reflection

Today's work helped me connect development with deployment. Writing code is only one part of building a project; making it accessible to others is equally important. Publishing my portfolio gave me confidence and helped me understand an essential step in the web development process.
